# Data release status

Curated simulation outputs have not yet been added to this repository.

Before release, the output archive will be checked to:

- remove API keys, local filesystem paths, request headers, and unrelated logs;
- retain run-level results needed to reproduce the manuscript's descriptive summaries;
- document the mapping from source files to manuscript tables and figures;
- distinguish original model outputs from derived tables and plots;
- include file checksums and a data dictionary.

The code release is usable for configuration inspection, plan generation, and rerunning the experiments. Exact manuscript table and figure reproduction will require the forthcoming curated result files.
